Binance Square
Automation

A server-side integration scaffold for approved Binance Square text and image posts, with an optional scheduled CoinDesk crypto-news workflow.

Live publishing is not automatic by default. API credentials, MCP secret, and news settings must be configured in Vercel. Scheduled news runs in dry-run mode unless explicitly enabled.

Health endpoint

Check whether the Vercel function is reachable and which environment variables are present (secret values are never returned).

MCP publishing

Connect a compatible MCP client using the secret endpoint after configuring MCP_SECRET_PATH.

News automation

Requires a protected cron secret and persistent Redis storage for duplicate-news tracking before live posting.
